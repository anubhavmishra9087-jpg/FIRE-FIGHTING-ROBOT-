                                FIRE FIGHTING ROBOT 
This  Fire Fighting Robot is a Computer Science Engineering (CSE) project that integrates embedded systems, sensors, and automation to detect and extinguish fire autonomously. It uses flame and smoke sensors, obstacle avoidance, and a water pump to improve safety while demonstrating practical applications of robotics, IoT, and intelligent.
